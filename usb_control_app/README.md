# 轻控 1.0.9

一个轻量、离线、中文原生 Android 工具。Java + Android SDK，无第三方运行时、无 WebView、无广告或网络权限。最低 Android 8.0 / API 26，目标 API 36。

## 安装

安装 `../releases/usb-control-v1.0.9.apk`，打开「轻控」，在 SukiSU / KernelSU / Magisk 管理器中授予 Root。无需先安装原 USB 调试模块；已安装时仍可继续使用，切换后会刷新旧模块的状态描述。

首次成功连接 Root 时将初始系统值原子保存到 `system-baseline.properties`，缓存写入或恢复脚本生成失败时停止启用系统操作，之后不把修改后的值覆盖成初始值。没有 Root 或读取失败时，系统开关置灰；选图、取景、透明度调整仍正常使用，且图片任务与 Root 队列相互独立。

## 功能

### 运营商注册组件清单（1.0.9）

- 从本地 TelemetryCleaner 的完整目录导入 13 个精确包名（不是仅 4 项自动清理名单），加上原有 5 个包名共 18 个候选。
- 卸载和恢复共用同一白名单及现有美化弹窗；未预装、非系统包不展示，默认不勾选。不增加后台自动清理或跨用户批量操作。
- 保留上游 7 项「未验证」标记；上游实测标记不代表轻控已经在相应机型验证。卸载注册组件可能影响运营商注册相关功能，请按需选择。
- 仍删除卸载目标的数据；恢复仅恢复应用，不找回数据。目标、来源提交及验证边界见 [`运营商组件清单`](../docs/usb-control-telemetry-targets.md)。

### 系统应用弹窗外观（1.0.8）

- 卸载、恢复共用自定义圆角弹窗，复用主页的蓝色、卡片和浅/暗主题；应用名称、分类标记与包名分层展示。
- 支持整行点选、全选/取消全选、实时已选数量。默认不勾选，未选择时下一步置灰。
- 选择和确认在同一弹窗内切换；返回选择保留勾选，取消和关闭不执行操作。
- 卸载数据风险、恢复不找回数据的提示保留；底部操作固定，内容区域可滚动适应较小窗口和较大字体。
- 仅修改呈现层，不改变系统包白名单、用户范围、无 `-k` 卸载命令、恢复方式和执行前后读回校验。
- 详情与验证边界见 `../docs/usb-control-system-apps-dialog/README.md`。

### 系统应用管理（1.0.7）

- 在「05 / 系统应用管理」中勾选目标，再确认批量卸载；默认不勾选任何项。
- 固定包名白名单：快应用 `com.miui.hybrid`、内容中心 `com.miui.newhome` / `com.miui.contentcenter`、浏览器 `com.android.browser`、系统广告 `com.miui.systemAdSolution`。
- 仅展示本机包管理器确认的系统应用；未预装的包不展示。不把传送门 `com.miui.contentextension`、内容抓取或第三方浏览器归入目标。
- 使用 `pm uninstall --user USER_ID PACKAGE`，不使用保留数据的 `-k` 参数；卸载轻控所在 Android 用户的应用并删除应用数据，不删除系统分区 APK。数据删除不可撤销，卸载浏览器可能影响网页打开。
- 「恢复已卸载的系统应用」使用 `cmd package install-existing --user USER_ID PACKAGE` 恢复系统仍保留的预装包；不强制改变其启用状态，也不恢复卸载时删除的应用数据。
- 执行前重新检查系统包身份和安装状态，每项执行后精确匹配包名读回，单项失败仍继续其他已勾选项。恢复入口也可恢复此前由其他工具卸载的白名单系统包。
- 原「恢复首次使用前的系统设置」仅针对 USB / 显示，不恢复系统应用，请使用单独的应用恢复入口。
- 当前连接设备未发现内容中心预装包。卸载/恢复行为已通过模拟包管理器测试；未为测试卸载手机上的实际系统应用。

### 连接控制

- **USB 调试**：读写 `global/adb_enabled`，开启时启用开发者选项；关闭前确认提示会中断 USB ADB。不自动开启无线调试，不删除 RSA 授权。
- **USB 安装**：检测 `global` / `secure` / `system` 表中已存在且为 0/1 的 `adb_install_enabled`；恰好一个候选时启用，缺失、异常或歧义时置灰。写入后读取校验。
- 这是保守适配，不声称覆盖全部 ROM。独立开关不属于统一 Android API；使用私有服务、账号校验或其他存储的厂商系统会置灰。不会创建猜测键，不把安装验证器、未知来源或「USB 调试安全设置」当作 USB 安装开关。现有键的读回成功不等于厂商安装器全链路已验证。

### 最小宽度

- 同时显示 dp 和当前逻辑 dpi；可输入 280–720 dp 或使用 360 / 393 / 411 / 480 预设。
- 按当前有效短边像素计算 `dpi = round(shortSidePx * 160 / smallestWidthDp)`，使用 `wm density`，不修改物理分辨率。
- 约 20 秒独立 Root 看门狗：每次预览独立脚本和持久化日志，以原子文件改名决出确认/超时的唯一赢家，恢复后读取校验。前台预览保持亮屏，后台以 `/proc/uptime` 计时，休眠唤醒后立即检查超时，最多约一秒轮询延迟。点击「保留」才提交；也可恢复系统默认。
- 看门狗不跨手机重启运行；若预览期间手机重启，下次打开 App 会恢复未确认的旧密度。应先确认或还原后再重启。
- 折叠屏、桌面模式、多屏及厂商额外显示缩放可能改变系统最终 dp，当前针对默认主显示屏。

### 自定义背景

- 使用系统文件选择器，选取手机上的图片；不索取相册全量访问或存储权限。
- 图片由 Android 解码，长边限制到约 2048 像素，复制到 App 私有目录。Android 9+ 使用 ImageDecoder；Android 8 使用平台 ExifInterface 校正八种方向。解码、持久化均在独立图片队列执行。
- 始终等比 cover 缩放；单指拖动选区，双指等比放大 1–4 倍，不提供变形拉伸。
- 「图片透明度」滑块：0% = 完全显示，100% = 完全透明。实时预览真实主界面卡片叠加效果；白色高不透明度卡片确保文字可读。
- 保存新图片文件并同步后才提交取景与透明度；失败时保留旧图片和设置，保存期间锁定取消与编辑；活动销毁后不再更新旧窗口。取景窗口随旋转调整预览比例。取消不修改已保存背景；删除背景仅删除 App 内副本。
- 图标资源是根目录所给 PNG 的原样副本，不重绘图像。系统桌面按自己的图标蒙版裁切。

## 回滚与卸载

推荐先在 App 点击「恢复首次使用前的系统设置」，再卸载。只卸载 App 不会自动恢复已经提交的系统设置。旧 KernelSU USB 模块仍保持独立生命周期，不会随 App 卸载而删除。

首次 Root 读取后还会生成本机恢复脚本，紧急情况下在手机 Root 终端执行：

```sh
su -c 'sh /data/user/0/local.usbcontrol/files/restore-system.sh'
```

电脑侧（用户 0）恢复并卸载：

```powershell
.\scripts\rollback-usb-control-app.ps1 -Serial DEVICE_SERIAL
```

从未获得 Root、未修改系统时可加 `-UninstallOnly`。恢复脚本来源于本机初始值，不使用通用默认值覆盖手机。

## 构建

```powershell
.\usb_control_app\build.ps1 -Sdk F:\Android\Sdk
```

需 JDK 21（编译 Java 8 字节码）、Android SDK Platform 36、Build Tools 35.0.0。也可通过 `ANDROID_SDK_ROOT` 指定 SDK。无需 Gradle 或下载应用依赖。构建前校验构建路径并清理生成目录，避免旧 class 混入。

输出 `releases/usb-control-v1.0.4.apk` 和 `.apk.sha256`。本地签名密钥为 `%USERPROFILE%\.android\usbcontrol-local.jks`（本地构建口令 `android`），不入仓库；请另行备份以便后续覆盖更新。此口令用于个人本地构建，不是商店发行的密钥管理方案。

## 验证

`tests/LogicTest.java` 覆盖能力检测、歧义、密度换算、参数边界及图像等比缩放。`tests/ui_smoke.py` 在专用无 Root 模拟器测试最终 APK 的禁用状态、背景、透明度预览及持久化。Root 命令集测试使用独立 AOSP userdebug 模拟器，测试专用 `su` 参数适配脚本不包含在交付 APK。

1.0.0 的历史交付记录保留在 `../docs/usb-control-app/`；1.0.1 的逐轮审查、真实 OnePlus / Android 16 Root 回归、签名、DEX 与资源检查见 `../docs/usb-control-audit/`。真机 USB 安装键缺失，已验证置灰；未伪造系统键，不把合成值的读回当作厂商安装策略验证。

技术依据：[AOSP WindowManagerShellCommand](https://android.googlesource.com/platform/frameworks/base/+/master/services/core/java/com/android/server/wm/WindowManagerShellCommand.java)、[Android 系统文件选择器](https://developer.android.com/training/data-storage/shared/documents-files)、[RedMagicX 的 USB 安装键实现说明](https://github.com/XPRAMT/RedMagicX)。

### 外观模式（1.0.2）
在「03 / 你的风格」中选择「外观模式」：跟随系统（默认）、浅色、暗色。选择自动记忆；暗色同时适配卡片、文字、系统栏、弹窗及背景透明度预览，不改变图片原色、裁剪位置或透明度。
暗色模式验证记录：`../docs/usb-control-dark-mode/`。

### USB 安装兼容性（1.0.3）
新增 Xiaomi / MIUI / HyperOS 安全中心接口适配：读取真实开关状态，关闭后读回核对；开启时进入系统原有验证页面，完成或取消后返回自动刷新。没有对应接口的系统继续置灰；标准设置键适配保留。恢复初始开启状态同样遵循系统确认，不改动账号、安装验证、未知来源或 USB 调试安全设置。
验证与回滚见 `../docs/usb-control-usb-install/`。

### 直接切换（1.0.4）
USB 调试和 USB 安装的开启、关闭均取消 App 二次确认；点击立即显示处理中状态，核对系统读回后完成。切换仅读取相关状态，避免重复全量扫描和恢复文件写入；小米系统自身的开启验证流程保留。密度预览、还原设置、删除背景等其他确认不变。
验证记录：`../docs/usb-control-fast-toggle/`。

### 一键循环壁纸（1.0.5）
在「04 / 壁纸小工具」点击「一键循环壁纸」，需要 Root。

本台小米手机已实测的目录（主用户 0）：
```text
/sdcard/Android/data/com.android.thememanager/files/MIUI/.videowallpaper/
```
规则：仅处理目录直属普通 MP4 文件，文件名为 `LocalImport` + 一个或多个 `_` / `&` + 32 位十六进制标识。分隔符统一为 `_&_`，保留后面的标识和视频字节。无扩展名是正常情况，文件头为 MP4 的 `ftyp`。

- 已规范文件不动，重复点击幂等。同名目标存在时跳过并显示冲突数，不覆盖文件。
- 不递归；跳过 `_split` 目录、符号链接、非视频、异常命名及带扩展名的文件。
- 目录不存在时提示先用主题管理导入，不创建猜测目录。
- 后台串行处理，处理中禁用按钮；内核锁防止重入，进程退出及重启自动释放。大视频校验最多等待 10 分钟。
- SHA256 校验并在 App 私有目录保存累计未撤销的原名记录。「撤销壁纸改名」经确认后还原；重名或内容变化时跳过，保留记录。
- 卸载会清除私有撤销记录，请先撤销再卸载。系统设置恢复按钮不包含壁纸改名。
- 只做用户指定的文件名修正，不自动应用、切换壁纸或改变播放参数。处理后到主题管理重新选择壁纸查看循环效果。

验证及回滚材料：`../docs/usb-control-wallpaper/`。多轮真机隔离测试及轻控自身进程的 Root 集成测试通过；按用户要求不执行截图或界面查看，实际播放效果未纳入本次验证。

发布前审查补充：新改名与撤销均先验证完整撤销日志；记录写入后同步落盘，再改名并校验内容。支持中断前后恢复；拒绝损坏或缺少结束换行的日志。App 私有目录异常（符号链接）在写脚本前拦截；仅支持主用户，避免误操作另一用户的壁纸。
