# 轻控 v1.0.7 · 可勾选卸载系统应用

## 新功能

- 新增「系统应用管理」，可勾选快应用、内容中心、系统浏览器、系统广告 adsolution，一键批量卸载。
- 自动识别本机存在的目标系统包，默认不勾选，执行前再次确认，完成后逐项显示结果。
- 卸载不保留应用数据；仅作用于轻控所在 Android 用户，不删除系统分区安装包。
- 提供独立的应用恢复入口：仅重新安装系统预装应用，不恢复卸载时删除的数据。

## 使用说明

安装或覆盖更新 APK 后，在主页「05 / 系统应用管理」操作。系统操作需要 Root；Android 8.0+。目标包名按小米 / MIUI / HyperOS 预置白名单识别，其他 ROM 或未预装包不会自动匹配。当前测试手机未发现内容中心预装包，因此未实测该项。

**卸载会删除应用数据，此数据删除不可撤销。卸载浏览器等应用可能影响关联功能。恢复应用不等于恢复数据。**

## 验证与附件

- 24 项系统应用模拟测试及原有回归测试通过，覆盖删除数据、未选项隔离、恢复不复活数据、读回校验和单项失败继续。
- APK 签名、对齐、版本、SHA-256 及 ZIP 完整性校验通过。
- 已在连接手机更新安装；勾选、确认及恢复入口经过界面检查。没有为测试卸载或清除实际系统应用，真实 ROM 上的数据删除未实测。
- 附件提供 APK、校验文件、从 v1.0.5 到 v1.0.7 的源码补丁、验证与源码回滚材料。源码回滚不恢复已删除的手机应用数据。

应用离线运行，无网络权限，不收集数据。
