# 轻控 1.0.7：卸载不保留应用数据

基线为本工作区已交付的 1.0.6，不重置前一轮系统应用功能。

- `SystemApps.command` 的卸载分支移除 `-k`，现在执行 `pm uninstall --user USER_ID PACKAGE`。仍限定轻控所在用户，不删除系统分区 APK。
- 功能卡片、卸载确认、处理结果与恢复提示均明确不保留应用数据；恢复只恢复应用，不恢复删除的数据。
- 新增模拟测试验证所选应用数据被删除、未选应用数据不变、重新安装不复活已删除数据；共 24 项系统应用测试，原有回归测试通过。
- 已构建、签名校验并更新安装到连接手机。没有对手机上的实际系统应用执行卸载或清除数据，真机数据删除行为未实测。

交付物：`../../releases/usb-control-v1.0.7.apk`、`changes.patch`、`verification.json`、`../../scripts/rollback-usb-control-delete-data.py`。

验证记录包含基线与新版测试的命令、原样输出和退出状态，以及构建、安装、包列表不变、反向补丁检查和副本回滚验证。回滚原件在 `rollback-originals.zip`，运行回滚脚本恢复项目源码和发布包至 1.0.6；不会自动降级手机，也不会恢复手机上已删除的应用数据。
