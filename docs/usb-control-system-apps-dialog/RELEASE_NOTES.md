# 轻控 v1.0.8 · 系统应用弹窗焕新

## 外观与交互

- 卸载、恢复系统应用的勾选与确认弹窗统一为轻控的圆角卡片、蓝色强调和浅/暗主题。
- 应用名称、分类标记、包名分层展示；支持整行勾选、全选/取消全选与实时已选数量。
- 未勾选时禁用下一步，返回选择保留勾选；固定底部操作，内容可滚动，适配较大字体及横屏。
- 保留卸载删除数据、恢复不找回数据的提示。

## 审查修复

- 隔离旧页面排队的点击，避免快速连点越过确认或改变已经展示的确认选择。
- 屏蔽关闭后旧确认按钮的提交；最终操作仅提交一次。
- 操作前检查 Activity 与后台状态，状态变化时给出提示，避免静默丢弃操作。
- 补充勾选行的读屏状态，避免重复朗读子标签。

## 验证与范围

- 保留原卸载/恢复后端，白名单、用户范围、删除应用数据的卸载命令及读回校验不变。
- 多轮主机回归、签名、对齐、版本及校验值检查通过；最后两轮真机界面测试各 68 项通过，无跳过项。
- 覆盖浅/暗主题、卸载/恢复、选择/确认/返回、旧点击隔离、重复提交、读屏状态、较大字体和横屏。
- 界面测试使用虚拟条目及计数回调，没有实际卸载或恢复手机系统应用；不宣称所有 ROM 的实操兼容性均重新验收。

安装包可覆盖更新已有同签名轻控。系统操作仍需 Root，应用不增加网络或其他权限。

附件包含 APK、APK 校验值、源码补丁、验证/回滚材料 ZIP 和附件校验清单；不包含签名私钥、完整手机日志、实际应用列表或个人背景截图。
