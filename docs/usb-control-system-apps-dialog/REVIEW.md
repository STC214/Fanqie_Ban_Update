## 第一轮：布局与基本流程

检查浅/暗主题、卸载/恢复两个入口、默认未选、整行点选、全选、选择与确认切换、返回保留勾选和取消。初次真机检查 52 项通过。检查组件绘制后缩短风险提示，避免窄屏出现孤立尾字；保持用户认可的整体外观。

## 第二轮：生命周期与旧事件

审查并修复以下边界：

- 关闭后的确认控件仍可能收到旧点击：增加弹窗活动状态检查。
- 页面切换后旧“下一步”事件可能被解释为当前确认事件：每次渲染使用独立交互代次，忽略旧代次事件。
- 旧全选/勾选控件可能改变确认页对应的选择：同样进行代次隔离，保证确认的是已展示的条目。
- 后台刷新或 Activity 销毁后提交：宿主在调用任务前核对生命周期与后台状态，必要时明确提示。
- 数组长度使用原始参数而非列表快照：统一以复制后的列表计算。
- 读屏重复朗读子标签：勾选行提供统一的可勾选/已选状态，子标签不重复暴露。

补充对应回归测试，包括旧下一步、旧全选/行点击、关闭后旧确认以及重复提交；所有提交都使用计数回调，不触发实际系统应用操作。
