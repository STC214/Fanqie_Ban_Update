# 轻控 v1.0.5 · 一键循环壁纸

新增「04 / 壁纸小工具」：
- 一键规范主题管理本地视频壁纸文件名：`LocalImport` 后的分隔符统一为 `_&_`，保留后面的 32 位标识与视频字节。
- 支持累计撤销，SHA256 校验；重名不覆盖，异常文件、目录和符号链接跳过。
- 日志完整性校验、写前日志落盘、中断恢复、内核锁防重入；需要 Root，仅适配手机主用户。

适配目录：
`/sdcard/Android/data/com.android.thememanager/files/MIUI/.videowallpaper/`

多轮审查修复与回归通过：477 条原有逻辑断言、新增真机隔离测试、轻控自身进程 Root 集成测试、APK 签名/对齐/哈希及回滚验证。真实目录现有 5 个视频文件名及内容未改变。

此功能只按指定规则改文件名，不自动应用或切换壁纸。处理后在主题管理重新选择壁纸，实际循环表现由系统决定。按用户要求未进行截图或界面查看。

安装 APK 前可核对 `.apk.sha256`。应用仍为离线工具，无网络权限；卸载前建议先在 App 内撤销壁纸改名（卸载会清除撤销记录）。
