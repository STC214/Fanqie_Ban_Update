# 轻控 1.0.4：直接切换与顶部署名

## 改动

- USB 调试、USB 安装的开启与关闭都移除 App 二次确认，单击直接提交操作。
- 点击立即显示目标开关和处理中状态；完成后使用系统读回值。失败不会伪报成功，控件停用并显示错误，可点击 Root 状态重试。
- 两类开关都不再在切换路径执行完整系统/屏幕扫描或重新写入基线与恢复文件。
- USB 调试写入与读回合并为一次 Root 调用；旧模块描述更新后台执行、不等待。
- USB 安装键存在性检查、操作、读回合并在一次 Root 命令；小米开启仍调用系统原有验证页面，返回后仅刷新对应安装状态。系统自身验证不是 App 确认弹窗，不强制修改安全中心私有文件或开启值。
- 保留忙状态防连点、密度事务保护及恢复/背景删除等其他确认。
- 顶部小号淡色副标题为 **USB & DISPLAY 「BY STC214」**，使用现有主题次级文字色，浅/暗模式共用。

## 验证

- 真机普通 App 单次点击分别改变 USB 安装实际状态，无需点击 App 确认按钮；系统 provider 的关闭、开启读回均通过，最终恢复原值。USB 调试、无线调试、密度保持原值。
- 主机观察耗时（含 ADB 输入、命令与轮询）见 `phone-summary.json`；不是纯 UI 帧延迟或与 1.0.3 的严格基准比较。数次优化中重复测试了开关，但最终增加署名仅改变文字；最终大写署名已从 DEX 核对，并核对手机安装包 SHA-256 一致。
- 没有在当前开发连接上切断 USB 调试。两个调试方向共用的直接执行函数与 USB 安装函数均通过源码回归检查：无对话框、无全量刷新。
- 基线 29 + 420 项断言；修改版 34 + 420 项断言；适配/恢复命令 23 项断言全部通过。
- 签名、ZIP、对齐、原图标一致性通过；lint 0 错误，保留之前 3 条兼容提示。
- 补丁在基线副本真实应用后比较；回滚脚本在修改版临时副本执行并逐字节核对。原 1.0.3 APK 与封存基线均保留不变。
