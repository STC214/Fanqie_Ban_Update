## 验证边界

主机模型覆盖包名精确匹配、用户范围、卸载删除数据、恢复不找回数据、执行前重验、逐项失败继续、读回检查及无关应用隔离。
独立 Android 15 模拟器覆盖浅暗色、大字体、18 项列表和确认页、横屏、重复点击隔离与取消不提交。
最后两轮在覆盖范围内未发现新增问题；实体手机当前未连接，未为本次测试卸载任何手机系统应用，也不宣称所有厂商 ROM 均完成卸载实测。

安装包签名与 1.0.8 一致，可覆盖更新同签名轻控。附件包含 APK、校验值、补丁及验证 / 源码回退材料，不包含签名私钥、手机日志、手机应用清单或上游完整克隆。
